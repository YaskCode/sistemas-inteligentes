# Tema 1: Ingeniería del Conocimiento y Sistemas RAG

## Pregunta orientadora

¿Cómo construir el conocimiento de un sistema inteligente?

## Objetivo

Modelar conocimiento especializado y construir un sistema RAG capaz de recuperar información pertinente y generar respuestas contextualizadas.

## Contenidos

- Ingeniería del Conocimiento.
- Representación del Conocimiento.
- Ontologías ligeras y taxonomías.
- Embeddings.
- Estrategias de segmentación o chunking.
- Bases de datos vectoriales.
- Arquitectura Retrieval-Augmented Generation.
- Ingesta, indexación, recuperación y generación.
- Evaluación de recuperación y calidad de respuestas.
- Diseño de conocimiento especializado para dominios concretos.
