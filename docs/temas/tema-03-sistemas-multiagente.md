# Tema 3: Sistemas Multiagente y Orquestación

## Pregunta orientadora

¿Cómo orquestar múltiples agentes para resolver un problema complejo?

## Objetivo

Construir un sistema multiagente coordinado mediante comunicación, delegación, patrones de orquestación y mecanismos de observabilidad.

## Contenidos

- Sistemas y arquitecturas multiagente.
- Coordinación y colaboración.
- Comunicación y protocolos de interacción.
- Orquestación.
- Patrones Supervisor, Sequential, Hierarchical y Swarm.
- Model Context Protocol (MCP).
- Agent-to-Agent (A2A).
- Evaluación y observabilidad.
