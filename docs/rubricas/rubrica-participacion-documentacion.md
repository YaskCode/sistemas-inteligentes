# Rúbrica de participación, asistencia y documentación

| Criterio | Peso |
|---|---:|
| Participación académica y colaboración | 30 % |
| Asistencia y puntualidad | 20 % |
| Documentación continua | 25 % |
| Trazabilidad en Issues y Pull Requests | 15 % |
| Reflexión y respuesta a retroalimentación | 10 % |

La actividad se evalúa por su calidad y continuidad, no por el número aislado de mensajes o commits.
