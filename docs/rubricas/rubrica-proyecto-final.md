# Rúbrica del proyecto final

| Criterio | Peso |
|---|---:|
| Integración coherente de RAG, agentes y orquestación | 25 % |
| Arquitectura y calidad técnica | 20 % |
| Funcionamiento y experiencia demostrada | 20 % |
| Evaluación, pruebas y observabilidad | 15 % |
| Documentación y reproducibilidad | 10 % |
| Presentación, demo y defensa | 10 % |

Se valorará la integración real de los sprints y no la simple acumulación de componentes.
