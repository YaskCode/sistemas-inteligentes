# Rúbrica general de sprints

| Criterio | Peso |
|---|---:|
| Comprensión y aplicación del tema | 25 % |
| Diseño y decisiones técnicas | 20 % |
| Implementación funcional | 25 % |
| Pruebas y evaluación | 15 % |
| Documentación y trazabilidad | 10 % |
| Presentación y respuesta a observaciones | 5 % |

La calificación se aplica al valor particular de cada sprint. Un entregable sin evidencia reproducible no se considera completo.
