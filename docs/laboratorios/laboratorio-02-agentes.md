# Laboratorio 2: agentes inteligentes

## Objetivo

Refactorizar el Wellness Agent como agente especializado con memoria, herramientas y patrón de razonamiento.

## Actividades

1. Definir rol, responsabilidades y límites.
2. Diseñar prompt especializado.
3. Implementar memoria conversacional.
4. Integrar al menos una herramienta.
5. Aplicar ReAct u otro patrón justificado.
6. Evaluar comportamiento, errores y limitaciones.

## Herramientas sugeridas

Google ADK y Gemini API; LangGraph como introducción; CrewAI y LangSmith como opciones de comparación o evaluación.

## Evidencias

Diagrama, contratos de herramientas, código, pruebas, trazas y análisis crítico.
