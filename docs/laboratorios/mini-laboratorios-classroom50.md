# Mini laboratorios y Classroom 50

Classroom 50 se contempla como integración complementaria futura para ejercicios individuales o repetibles.

## Usos previstos

- distribuir un ejercicio base;
- establecer fecha y criterios;
- ejecutar pruebas automáticas;
- ofrecer retroalimentación rápida;
- repetir prácticas esenciales;
- evaluar competencias individuales antes de un sprint.

Su incorporación no sustituirá GitHub Project, Issues, ramas ni Pull Requests como núcleo de dirección del proyecto Wellness 2.0.
