# Laboratorio 3: sistema multiagente

## Objetivo

Diseñar y probar una arquitectura multiagente coordinada.

## Actividades

1. Definir orquestador y agentes especializados.
2. Modelar roles, comunicación y delegación.
3. Implementar un flujo multiagente.
4. Integrar fuentes o herramientas necesarias.
5. Probar delegación correcta, colaboración, errores y tiempos.
6. Documentar observabilidad y limitaciones.

## Herramientas sugeridas

Google ADK, LangGraph o CrewAI, Gemini API, Firestore, BigQuery, GitHub y Mermaid.

## Evidencias

Arquitectura, diagrama de orquestación, flujo, código, pruebas y resultados.
