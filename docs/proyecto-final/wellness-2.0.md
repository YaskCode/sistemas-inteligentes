# Wellness 2.0

Wellness 2.0 evoluciona la plataforma construida en Ingeniería de Software y Bases de Datos.

## Punto de partida

Arquitectura cloud-native, microservicios, nube, Firestore, BigQuery y primer agente.

## Evolución

La plataforma incorpora:

- base de conocimiento wellness y RAG;
- agente orquestador;
- Wellness Coach Agent;
- Nutrition Agent;
- Analytics Agent;
- Motivation Agent;
- otros agentes justificados por el equipo;
- memoria, herramientas, coordinación y observabilidad.

El sistema debe apoyar rutinas, objetivos y seguimiento sin sustituir profesionales de salud ni formular diagnósticos médicos.
