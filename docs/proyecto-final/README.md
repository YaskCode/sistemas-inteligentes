# Proyecto final: Wellness 2.0

**Valor:** 40 %.

El proyecto integra los resultados de los tres sprints para evolucionar la plataforma cloud-native previa hacia un sistema inteligente basado en conocimiento, agentes especializados y orquestación.

La implementación se desarrolla en **computing-laboratory**. Este repositorio contiene las instrucciones comunes.

## Capacidades esperadas

- recuperación contextual mediante RAG;
- Wellness Coach Agent y agentes especializados;
- memoria y herramientas;
- Orchestrator Agent;
- coordinación y comunicación;
- integración con servicios y datos existentes;
- evaluación, observabilidad y documentación.
