# Entregables del proyecto final

- sistema integrado y funcional;
- arquitectura y diagrama de orquestación;
- código en el repositorio del equipo;
- README de instalación, configuración y uso;
- decisiones técnicas y limitaciones;
- pruebas y resultados de evaluación;
- evidencias de ejecución o despliegue;
- trazabilidad mediante Issues, ramas y Pull Requests;
- video demostrativo;
- presentación técnica;
- documentación final.

La entrega debe señalar qué partes proceden de los sprints y cómo fueron integradas.
