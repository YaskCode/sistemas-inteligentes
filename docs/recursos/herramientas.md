# Herramientas

| Área | Herramientas de referencia |
|---|---|
| Desarrollo y colaboración | GitHub, Codespaces, Python, Google Colab |
| Gestión | GitHub Project, Issues, ramas y Pull Requests |
| Infraestructura | Google Cloud |
| Documentación | Markdown y Mermaid |
| Modelos | Gemini API y Vertex AI |
| Conocimiento y RAG | ChromaDB, FAISS, LangChain o LlamaIndex |
| Agentes | Google ADK, LangGraph y CrewAI |
| Persistencia | Firestore y BigQuery |
| Evaluación y observabilidad | LangSmith y OpenTelemetry |

La selección final debe justificarse. No es obligatorio utilizar simultáneamente todos los frameworks.
