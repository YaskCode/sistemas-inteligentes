# Semana 4 — Artículos Científicos e Integración Final

## Objetivo
Integrar inteligencia artificial generativa y procesos de MLOps en una solución funcional desplegada en la nube.

## Teoría
- IA Generativa / Ingeniería de Prompts / APIs de IA
- Vertex AI / Fundamentos de MLOps

## Sprint Técnico
Cada equipo integrará funcionalidades inteligentes en su plataforma, desplegará el sistema completo y realizará la presentación final del proyecto.

- Integración IA funcional
- API inteligente conectada

- Evidencias funcionales
