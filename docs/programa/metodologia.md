# Metodología

El curso combina aprendizaje activo, discusión de artículos, walkthroughs, laboratorios y desarrollo incremental de Wellness 2.0.

## Dirección de los sprints

La profesora actúa como directora de orquesta:

- organiza objetivos y prioridades mediante GitHub Project;
- publica o valida Issues y criterios de aceptación;
- revisa ramas y Pull Requests;
- orienta decisiones técnicas y académicas;
- controla hitos, evidencias y retroalimentación.

El estudiantado desarrolla la implementación en los repositorios de equipo de **computing-laboratory**. Este repositorio conserva las instrucciones y materiales comunes.

## Classroom 50

Classroom 50 es complementario. Podrá incorporarse en otra etapa para distribuir mini laboratorios individuales, repetibles y susceptibles de evaluación automatizada. No reemplaza GitHub Project ni el flujo basado en Issues y Pull Requests.

## Estrategias

- sesiones síncronas;
- actividades asíncronas;
- discusión de artículos científicos;
- walkthroughs dirigidos;
- laboratorios;
- tres sprints técnicos;
- ponencia/paper;
- proyecto final integrador.
