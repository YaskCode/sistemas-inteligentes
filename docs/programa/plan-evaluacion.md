# Plan de evaluación

| Componente | Valor | Evidencia principal |
|---|---:|---|
| Sprint técnico 1: RAG | 10 % | Conocimiento, pipeline RAG y evaluación |
| Sprint técnico 2: agentes | 15 % | Agente especializado funcional |
| Sprint técnico 3: multiagente | 15 % | Orquestador e integración |
| Ponencia/paper | 10 % | Exposición y documento académico |
| Proyecto final | 40 % | Wellness 2.0 integrado |
| Participación, asistencia y documentación | 10 % | Actividad sostenida y trazabilidad |
| **Total** | **100 %** | |

La evaluación considera producto, proceso y evidencia. Issues, commits, Pull Requests, documentación, pruebas y demostraciones aportan trazabilidad, pero la cantidad de contribuciones no sustituye su calidad ni la comprensión individual.

Las rúbricas se encuentran en [docs/rubricas](../rubricas/README.md).
