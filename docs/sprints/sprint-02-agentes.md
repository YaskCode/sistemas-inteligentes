# Sprint técnico 2: Agentes Inteligentes Modernos

**Valor:** 15 %.

## Objetivo

Diseñar un agente wellness especializado capaz de razonar, utilizar herramientas y mantener memoria.

## Entregables

- arquitectura y responsabilidades;
- prompt especializado y límites;
- flujo de razonamiento;
- agente funcional;
- memoria conversacional;
- integración de herramientas mediante Tool Calling;
- casos de prueba, evaluación y limitaciones;
- documentación y Pull Request.
