# Sprint técnico 3: Sistemas Multiagente y Orquestación

**Valor:** 15 %.

## Objetivo

Construir una plataforma multiagente coordinada para Wellness 2.0.

## Entregables

- arquitectura multiagente;
- diagrama de orquestación;
- roles y flujo de comunicación;
- Orchestrator Agent;
- agentes especializados;
- integración requerida con Firestore, BigQuery o APIs;
- pruebas de delegación, colaboración, calidad y tiempo;
- observabilidad, documentación y Pull Request.

Consulte la [rúbrica de sprints](../rubricas/rubrica-sprints.md).
