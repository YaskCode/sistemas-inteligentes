# Walkthrough: agente con herramienta

## Flujo

1. Definir propósito y límites del agente.
2. Especificar instrucciones y formato de salida.
3. Registrar una herramienta con contrato claro.
4. Proporcionar una consulta que requiera Tool Calling.
5. Observar decisión, argumentos, resultado y respuesta final.
6. Probar error de herramienta y solicitud fuera de alcance.

La traza debe permitir diferenciar razonamiento operativo, llamada de herramienta, observación y respuesta.
