# Walkthrough: orquestación con supervisor

## Flujo

1. Definir un agente supervisor.
2. Registrar dos agentes especializados con responsabilidades no solapadas.
3. Recibir una solicitud compuesta.
4. Clasificar o descomponer la tarea.
5. Delegar al agente apropiado.
6. Integrar resultados y responder.
7. Registrar decisiones, tiempos y errores.

Comparar el resultado con una ruta secuencial y analizar cuándo conviene cada patrón.
