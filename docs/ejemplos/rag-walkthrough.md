# Walkthrough: pipeline RAG mínimo

## Flujo

1. Seleccionar un conjunto documental pequeño y verificable.
2. Limpiar y segmentar el contenido.
3. Generar embeddings.
4. Indexar los fragmentos en una base vectorial.
5. Recuperar los fragmentos más relevantes.
6. Construir el contexto para el modelo generativo.
7. Responder con evidencia y registrar las fuentes.
8. Evaluar recuperación y fidelidad de la respuesta.

## Verificación

Probar preguntas respondibles, ambiguas y fuera del corpus. Registrar consulta, fragmentos recuperados, respuesta, fuente esperada y observaciones.
